Garth is where a team works with a coding agent in the browser, on its own
cluster. Someone opens a project, which is a git repository, and starts a
session. The agent works in a sandbox of its own, on a branch of its own, and
what it builds can be deployed to Toft.

## What it does

- **Projects are git repositories.** Start one empty or import it from GitHub
  or GitLab. The project's memory and skills live in its repository, so the
  agent reads them in every session. A project is shared with people and
  groups.
- **Each session runs in its own sandbox.** One person, one project, one
  branch and one pod. The sandbox holds no credentials, and it reaches the
  network only through Garth's proxy, to the destinations an administrator
  lists. Work that isn't pushed is saved after each turn and every few minutes,
  so it survives the sandbox.
- **You review and merge.** The Changes panel shows the diff. Commit and push
  sends it to the session's branch, and Merge puts it on the default branch.
- **Sessions can be shared.** Invite someone to watch a live session or to
  work in it with you.
- **Administrators see what it costs.** Spending by person, project and
  model, with budgets and spending alerts. Admin also covers who can join,
  single sign-on, the sandbox's network policy, models and the activity log.
- **It deploys to Toft.** Attach a Toft install, and the agent can deploy what
  it builds and check that it runs.
- **It runs on your machines.** One Go binary and SQLite, with sessions on
  Kubernetes, on a single node with k3s or on a cluster.

## Changed

- **Garth is free.** There is no license key, and Admin → License is gone.
  Garth no longer checks in with a license service.
- **The version follows Toft's.** This release is 0.10.0. It follows 0.0.6.
- **The documentation has moved** to
  [burnspring.github.io/garth-docs](https://burnspring.github.io/garth-docs/).
- **The session image is 0.4.9.**

## Fixed

- **Commits the agent makes itself can be pushed.** If the agent committed
  before the session's first push, the Changes panel said there was nothing to
  push, Commit and push stayed disabled, and Merge said nothing had been
  pushed. The panel now counts those commits, and Commit and push sends them.
- **The local administrator can sign in after Garth moves to a new address.**
  Signing in from a browser at the new address used to be refused.
